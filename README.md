Bu projeyi pubhtml5 sitesinde flipbook olarak yayınlanan bir kitabın pdf haline offline erişebilmek için düzenledim.
selenium ile ekran görüntüsünü çekerek görsel düzenlemeleri yapıp en son pdf olarak dosyayı kaydeden 3 parçadan oluşan python kodu.

##################################################################################################


önce main.py dosyasındaki bölümleri kendinize göre düzenleyiniz. (indeternet adresi vs.)
programı çalıştırdıktan sonra reklam vs açılırsa elle manuel kapatınız. 20 sn süreniz var uzatabilirsiniz.
data klasörüne ekran görüntüleri kayıt edilir.

2. bölümde main.py dosyasını çalıştırın.
burada ise ekran görüntüsü çift olan sayfalar tek tek ayrı sayfalar halinde kayıt edilir.
sayfa boyutları ve kesim yerlerini kendi ekran çöznürlüğünüze göre düzenlemeniz gerekir.
tüm dosyalar tek tek jpg halinde kesilmis_jpg kalsörüne depolanır.

3. bölümde ise bu dosyalardan tek pdf dosyası oluşturulur.
sayfalar naturel şekilde sıralanır. vekitap ile aynı sıralamada pdf formatına dönüşür.
çözünürlük ekranınıza bağlı olarak değişecektir. büyük çözünürlüklerde daha net sonuçlar alamk olası.

bekleme sürelerini internet hızınıza göre ayarlayabilirsiniz. Ben fazla fazla bıraktım sorun yaşamamak için.
